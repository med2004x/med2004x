# Med

**Backend Engineer** · Go · Python · PostgreSQL · Redis · Distributed Systems

I build backend services, APIs, and asynchronous processing systems. My main interests are database reliability, service boundaries, observability, and systems that behave predictably under failure.

## Selected work

### [PhoneClaw](https://github.com/med2004x/PhoneClaw)
**Flutter · Kotlin · Swift · Django · PostgreSQL · Redis**

A cross-platform mobile agent platform with native Android and iOS runtimes and a Django mission-routing backend. Android mission execution is implemented; iOS native role execution is still an explicit development boundary. The repository documents the current limits rather than reporting incomplete paths as successful.

### [Distributed Job Queue](https://github.com/med2004x/distributed-job-queue)
**Go · PostgreSQL · Redis**

A worker-backed job service with durable job records, retry scheduling, bounded attempts, dead-letter inspection, and replay. Includes a runnable stack and tests for retry and recovery behavior.

### [Transactional Outbox](https://github.com/med2004x/transactional-outbox)
**Go · SQLite · Docker Compose**

A runnable implementation of the transactional outbox pattern. Order state and outbound events are written atomically, then delivered by a background relay with retry and dead-letter handling. SQLite keeps this project scoped to single-writer workloads.

### [Multisurface API Gateway](https://github.com/med2004x/multisurface-api-gateway)
**Go · YAML · Docker Compose**

A configurable reverse proxy with API-key authentication, route-level rate limits, upstream health probes, and separate liveness/readiness endpoints.

### [Observability Stack](https://github.com/med2004x/observability-stack)
**Go · Prometheus · OpenTelemetry**

A runnable example of API instrumentation with request metrics, trace spans, health checks, and a local Prometheus setup. The checkout workload is simulated; this project demonstrates the telemetry path, not a real payment system.
